# 김정미 강사 홈페이지

빌드 과정이 없는 HTML/CSS/JavaScript 사이트입니다. `index.html`이 시작 페이지입니다.

## 콘텐츠 기준

1. 사용자가 첨부한 전체 구조 개편안을 최우선으로 적용했습니다.
2. 프로젝트 폴더의 랜딩페이지 기획서 PDF에서 교육 철학, 사례, FAQ와 업무 연락처를 보완했습니다.
3. 브랜드컬러 프로필 PDF에서 실제 프로필 사진, 출강 기관, 수상, 저서, 자격을 확인했습니다.
4. HWP 이력서 본문에서 2023–2026년 교육 경험과 과거 직책 기간을 확인했습니다.
5. 덕양행신 상상제작소 강의계획서 PNG 2장, 한경국립대 스토리북 강의계획서 PNG, 행정 실무 강의계획서 PDF를 읽고 프로그램 상세에 반영했습니다.

강의안은 실시 실적과 구분해 예시로 표기했습니다. 원본에 없는 수강생 수·만족도·기관 로고·현장 사진은 추가하지 않았습니다. 프로그램 이미지는 교육 주제를 표현하는 CSS 그래픽입니다.

## 문의

모든 강의 문의 버튼은 지정된 Google Forms 설문을 새 탭으로 엽니다. 사이트 내 입력 폼과 이메일 작성·복사 기능은 제거했습니다.
