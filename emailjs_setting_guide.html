EmailJS 문의 폼 설정 안내

이 안내서 안의 값과 HTML을 복사해 설정합니다. 안내서와 복사 기능은 인터넷 없이도 동작합니다. 대시보드 설정과 실제 메일 전송에는 인터넷이 필요합니다.

STEP 1 · 계정 · Gmail 서비스 연결

화면에서 누를 위치

EmailJS 로그인 → Email Services → Add New Service → Gmail → Connect Account에서 Gmail 계정을 연결하고 Create Service를 누릅니다. 기존 서비스가 있다면 해당 서비스를 엽니다. Service ID는 서비스 상세 화면에서, Public Key는 Account에서 확인합니다.

붙여넣을 값

Service ID
service_5p56j7b
Public Key
GM5MTL5OHAF_m9grb
Gmail 계정
jungmi31222@gmail.com

계정의 실제 ID가 위 값과 같아야 합니다. 서비스 테스트 메일 수신도 확인하세요. 비밀번호나 Private Key를 홈페이지 코드에 넣지 않습니다.

STEP 2 · 접수 알림 템플릿

화면에서 누를 위치

Email Templates → 기존 ID의 템플릿을 열거나 Create New Template → Settings에서 Template ID를 확인합니다. 템플릿 편집 화면의 수신자·제목 필드에 아래 값을 입력합니다. Content 편집기 우측 상단 코드 보기(< >)에서 HTML 모드로 바꾼 뒤 아래 HTML 전체를 붙여넣고 Save를 누릅니다. 편집기 버전에 따라 Code Editor 항목으로 표시될 수 있습니다.

붙여넣을 값

Template ID
template_asux0le
To Email
jungmi31222@gmail.com
From Name
{{from_name}}
Reply To
{{from_email}}
Subject
[문의] {{inquiry_type}} - {{from_name}}

From Email은 연결한 Gmail의 기본 발신 주소를 사용합니다. Bcc는 비워둡니다. To Email은 고정 주소를 유지합니다.

STEP 4 · Gmail 수신만 사용

화면에서 누를 위치

추가 전달 설정은 하지 않습니다. 사용자 요청에 따라 네이버 자동 전달과 Bcc는 사용하지 않습니다. EmailJS 템플릿의 수신 주소를 한 번 더 확인합니다.

붙여넣을 값

접수 알림 수신 주소
jungmi31222@gmail.com

Account의 허용 도메인 설정을 사용하는 경우 아래 홈페이지 주소를 등록합니다.

https://gangsa-five.vercel.app/

STEP 5 · 문의 내역 분류

화면에서 누를 위치

Gmail 상단 검색창의 검색옵션 표시 → 제목에 아래 조건 입력 → 필터 만들기 → 라벨 적용 → 새 라벨 → 필터 만들기를 누릅니다. 먼저 검색으로 실제 문의 메일이 잡히는지 확인합니다.

붙여넣을 값

제목 조건
[문의]
라벨 이름 예시
홈페이지 문의

처음에는 받은편지함 건너뛰기(보관)를 체크하지 않아 새 문의를 쉽게 확인하세요. 자동 보관이 필요하면 나중에 필터를 수정할 수 있습니다. 문의 처리 완료 후 1년이 지난 개인정보는 메일과 휴지통에서도 삭제하는 운영 절차가 필요합니다.

STEP 6 · 동작 테스트

화면에서 누를 위치

설정을 저장한 뒤 홈페이지 문의 폼에 본인이 받을 수 있는 이메일과 테스트 내용을 입력합니다. 동의를 체크하고 문의 보내기를 누릅니다. Gmail 받은편지함·스팸함과 EmailJS Email History를 함께 확인합니다.

붙여넣을 값

홈페이지 문의 주소
